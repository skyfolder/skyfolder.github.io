# Fortran 실습 채점기

브라우저만으로 도는 정적 페이지입니다. 서버도 빌드 도구도 필요 없습니다.
1장부터 14장까지 같은 구조로 늘려 갈 수 있게 만들었습니다. 현재는 2장이 들어 있습니다.

학생이 이름과 학번을 적고 시작해서 문제를 풀면, 마지막에 문항별 점수가 적힌 텍스트 파일이 만들어집니다.
한 문항에 1점이고, 2장은 50문항 만점입니다.

## 파일 구성

```
fortquiz.css                    공용 스타일        ← 모든 챕터가 함께 씀
fortquiz.js                     공용 엔진          ← 채점 규칙 + 화면 + 점수 기록

fort_prac_02.html               2장 실습 페이지
fort_prac_02_problems.js        2장 문제 (정답 없음)

answer/
  fort_prac_02_answers.js       2장 정답 지문 + 가려 둔 해설   ← 배포됨
  fort_prac_02_answers.src.js   2장 평문 정답 (강사용)         ← 배포 금지
  build_02.html                 2장 정답 재생성 도구            ← 배포 금지

score/                          점수 파일이 모이는 곳
.gitignore                      평문 정답과 강사용 도구를 커밋에서 제외
```

`fortquiz.css` 와 `fortquiz.js` 에만 챕터 번호가 없습니다. 14장까지 같은 코드를 열네 번 복사해 두면
채점 규칙 하나 고칠 때마다 열네 곳을 손봐야 하므로, 공용 부분은 일부러 한 벌만 두었습니다.
챕터마다 달라지는 것은 문제와 정답뿐입니다.

## 2장 문항 구성

| 구분 | 문항 | 출처 |
|---|---|---|
| 복습 | 1–18 | 수업 본문 예제 (chapter02) |
| 이론 | 19–38 | 출제 예상 문제은행 20문제 |
| 실습 | 39–50 | 절별 보충 예제 (2.1-1 ~ 2.4-2) |

답은 모두 한 줄 입력으로 끝납니다. 50번만 두 줄입니다.

## GitHub Pages에 올리기

1. 저장소를 만들고 파일을 루트에 올립니다. `.gitignore` 가 평문 정답과 강사용 도구를 자동으로 빼 줍니다.
2. 올린 뒤 저장소 웹 화면에서 `answer/` 안에 `fort_prac_02_answers.js` 하나만 있는지 눈으로 확인하세요.
3. Settings → Pages → Source를 `Deploy from a branch`, 브랜치를 `main` / `root` 로 지정합니다.
4. `https://<아이디>.github.io/<저장소이름>/fort_prac_02.html` 로 접속합니다.

로컬에서는 `fort_prac_02.html` 을 더블클릭하면 그대로 열립니다.

## 점수 기록 — 먼저 알아 둘 제약

**웹페이지는 서버의 `score` 폴더에 파일을 쓸 수 없습니다.** GitHub Pages는 읽기 전용이고,
브라우저도 보안상 임의 경로 쓰기를 막습니다. 그래서 실제로 가능한 두 방법을 모두 넣었습니다.

**score 폴더에 저장** — 크롬·엣지 데스크톱에서만 보입니다. 누르면 폴더 선택 창이 뜨고,
학생이 `score` 폴더를 지정하면 그 안에 파일이 바로 생깁니다. 저장소를 내려받아 쓰는
실습실 환경에 맞습니다. 학생 PC의 폴더에 쓰는 것이지 서버에 올리는 것이 아닙니다.

**파일로 내려받기** — 어느 브라우저에서나 됩니다. 다운로드 폴더에 `이름_챕터_점수.txt` 로
떨어지고, 학생이 LMS나 메일로 제출합니다.

점수를 자동으로 모으려면 채점 결과를 받아 줄 서버가 필요합니다. Google Forms나 Apps Script
엔드포인트로 보내는 방식이 가장 손이 덜 갑니다. `fortquiz.js` 의 `downloadReport` 근처에
`fetch` 한 번 추가하면 됩니다.

## 점수 파일

이름은 `이름_챕터_점수.txt` 입니다. 예: `홍길동_02_43.txt`

동명이인이 있으면 파일 이름이 겹칩니다. 학번을 넣으려면 `fortquiz.js` 의 `fileName()` 을 고치세요.

```js
return safeName(student.name) + '_' + student.sid + '_' + CFG.chapter + '_' + score() + '.txt';
```

파일 안에는 이름·학번·챕터·제출 시각·총점과 문항별 배점이 들어갑니다. 형식 예시는
`score/README.md` 에 있습니다. 채점하지 않은 문항은 `미응시`, 틀린 문항은 시도 횟수,
해설을 열어 본 문항은 `*` 로 표시되므로 학습 과정이 함께 남습니다.

Windows 메모장에서 한글이 깨지지 않도록 BOM을 붙인 UTF-8로 저장합니다.

## 정답이 새지 않게 한 방법

`answer/fort_prac_02_answers.js` 에는 평문 정답이 없습니다. 정답을 채점 규칙대로 정규화한 뒤
챕터 번호와 소금값을 섞어 구한 SHA-256 지문만 들어 있습니다. 채점은 학생 입력을 같은 방식으로
지문화해 비교하므로 정답 원문 없이도 동작합니다. 해설도 base64로 가려 두었습니다.

**다만 정직하게 말하면, 정적 페이지에서 완벽한 차단은 불가능합니다.** 채점 코드가 브라우저에
그대로 내려가므로 마음먹은 학생은 후보 답을 넣어 지문을 맞춰볼 수 있고, 보기가 넷뿐인 객관식은
특히 취약합니다. 이 구조가 막는 것은 "파일을 열어 정답을 그냥 읽는 일"까지입니다.
성적에 반영되는 시험이라면 채점을 서버에서 해야 합니다.

`base64`는 암호가 아니라 가림막입니다. 이 점을 감안해 해설을 쓰세요.

## 새 챕터 추가하기 (3장 예시)

1. `fort_prac_02.html` 을 `fort_prac_03.html` 로 복사하고 아래 네 곳을 고칩니다.
   - `<title>` 의 장 번호
   - `<script src="fort_prac_03_problems.js">`
   - `<script src="answer/fort_prac_03_answers.js">`
   - `FortQuiz.start({ chapter: "03", chapterTitle: "…" })`
2. `fort_prac_02_problems.js` 를 `fort_prac_03_problems.js` 로 복사해 문제를 새로 씁니다.
3. `answer/fort_prac_02_answers.src.js` 를 `answer/fort_prac_03_answers.src.js` 로 복사해 정답을 씁니다.
4. `answer/build_02.html` 을 `answer/build_03.html` 로 복사하고, 맨 아래 세 곳의 `02` 를 `03` 으로 바꿉니다.
   (`window.CHAPTER`, 문제 파일 경로, 정답 원본 경로)
5. `build_03.html` 을 열어 **생성하기 → 파일로 저장** 하고, 받은 파일을 `answer/fort_prac_03_answers.js` 로 둡니다.

`fortquiz.css` 와 `fortquiz.js` 는 손대지 않습니다.

## 정답을 고쳤을 때

정답 원본을 고쳤다면 반드시 해시를 다시 만들어야 합니다.

1. `answer/build_02.html` 을 브라우저로 엽니다.
2. **생성하기** → **파일로 저장** 을 누릅니다.
3. 받은 파일로 `answer/fort_prac_02_answers.js` 를 덮어씁니다.

`fortquiz.js` 의 채점 규칙이나 `SALT` 를 바꿨다면 **모든 챕터**의 정답 파일을 다시 만들어야 합니다.
안 그러면 전 문항이 오답 처리됩니다.

## 채점 기준

Fortran 문법의 관용을 반영해 아래 차이는 정답으로 인정합니다.

| 무시하는 것 | 예 |
|---|---|
| 대소문자 | `PRINT` = `print` |
| 들여쓰기·여분 공백 | `a  =  1` = `a=1` |
| 구두점 주변 공백 | `mod( n, 2 )` = `mod(n,2)` |
| 주석과 빈 줄 | `! 설명` 이하 삭제 |
| end 문 표기 | `end program hello` = `endprogram` |
| 관계 연산자 표기 | `.eq.` = `==`, `.ge.` = `>=` |
| 따옴표 종류 | `"abc"` = `'abc'` |
| 줄 연결 기호 | `&` 로 이어진 줄을 한 줄로 |

문자열 안의 내용은 대소문자까지 그대로 비교합니다. 출력 결과가 달라지기 때문입니다.

틀렸을 때는 "채점기가 읽은 내 답"으로 정규화 결과를 보여 주므로, 학생이 왜 틀렸는지
추측하지 않아도 됩니다. 두 번 틀리면 힌트가 자동으로 펼쳐집니다.

문제 유형은 네 가지입니다.

- `line` — 한 줄 코드. Fortran 규칙으로 느슨하게 비교합니다.
- `code` — 여러 줄 코드. 비교 규칙은 `line` 과 같고 입력 상자만 커집니다.
- `text` — 숫자, 기호, 명령어처럼 코드가 아닌 답.
- `choice` — 객관식. `options` 배열을 주고 정답에는 보기 번호(0부터)를 문자열로 적습니다.

## 알아두면 좋은 점

- 진행 상황을 브라우저에 저장하지 않습니다. 새로 고치면 답안이 사라지므로, 떠나려 할 때
  경고창이 뜨게 해 두었습니다. 세션을 이어 가고 싶으면 `fortquiz.js` 의 `state` 를
  `localStorage` 에 저장하는 코드를 넣으세요.
- 인정할 답이 여럿이면 `answers` 배열에 나열합니다. 14번은 곱셈·나눗셈 순서가 다른 세 표기를 모두 인정합니다.
- 보충 예제 2.4-3(정수·실수 나란히 선언)은 50번 한 문항으로 합쳤습니다. 50문항 제한 때문입니다.
