# 대기과학을 위한 인공지능 — 실습

브라우저만 있으면 되는 자율 학습용 실습 페이지입니다. 학생은 이름과 학번을 적고
문제를 풉니다. 답을 내면 그 자리에서 채점되고, **틀리면 고쳐서 다시 낼 수 있습니다.**
맞히면 그 문항이 닫히면서 해설이 열립니다. 마지막에 문항별 점수와 시도 횟수, 서명이
담긴 결과 파일을 내려받아 제출합니다. 한 문항에 1점입니다.

대문은 `AI_ML_atmos.html` 입니다. GitHub Pages에 올린 뒤 이 주소를 알려 주면 됩니다.

## 파일 구성

```
AI_ML_atmos.html                대문 — 1~14장 목록
aiquiz.css                      공용 스타일        ← 모든 장이 함께 씁니다
aiquiz.js                       공용 엔진          ← 채점 규칙 + 화면 + 점수 기록 + 서명

Ch07_AI_선형회귀.html            7장 실습 페이지
Ch07_problems.js                7장 문제 (정답 없음)

answer/
  Ch07_answers.js               7장 정답 지문 + 가려 둔 해설   ← 배포됩니다
  Ch07_answers.src.js           7장 평문 정답 (강사용)         ← 배포 금지
  build_07.html                 7장 정답 재생성 도구            ← 배포 금지
  build_answers.js              같은 일을 하는 명령줄 도구
  verify_score.html             제출물 검증 (강사용, 배포해도 무방)
.gitignore                      평문 정답과 강사용 도구를 커밋에서 제외
```

## 7장 문항 구성

| 구분 | 문항 | 형식 |
|---|---|---|
| 이론 | 1–15 | 객관식과 한 낱말 단답 |
| 코딩 | 16–35 | 교재 예제 프로그램의 빈칸 한 줄 채우기 |

코딩 문항은 모두 7.6~7.12절의 실제 예제를 그대로 싣고 그 안의 한 줄만 비워 둡니다.
학생은 앞뒤 코드와 실행 결과를 보면서 빠진 줄을 채웁니다.

## 채점 규칙

정답 평문은 배포 파일 어디에도 없습니다. `answer/ChNN_answers.js` 에는 장 번호와 문항
번호를 함께 섞어 만든 지문과 base64로 가려 둔 해설만 들어 있습니다. 학생의 입력도 같은
방식으로 지문으로 바꾸어 대조합니다.

대조하기 전에 입력을 다음과 같이 다듬습니다.

- 코딩 문항: 공백을 모두 지우고, 큰따옴표와 굽은 따옴표를 작은따옴표로 바꾸고,
  `#` 뒤의 주석을 떼어 냅니다. 대소문자는 구분합니다.
- 이론 문항: 공백과 문장부호를 지우고 소문자로 내립니다.

덕분에 `X=[[163],[179]]` 와 `X = [[163], [179]]` 는 같은 답으로 처리되고,
`regr` 을 `Regr` 로 쓴 코드는 틀린 답이 됩니다.

## 정답을 고치거나 새 장을 더할 때

1. `answer/ChNN_answers.src.js` 에 평문 답과 해설을 적습니다.
   객관식은 보기 번호를 0부터 세어 적고, 나머지는 받아들일 답을 배열로 적습니다.
2. `answer/build_NN.html` 을 열어 **생성하기 → 파일로 저장** 을 누르고,
   받은 파일로 `answer/ChNN_answers.js` 를 덮어씁니다.
   명령줄이 편하면 `node answer/build_answers.js 07` 로도 같은 일을 할 수 있습니다.
3. 새 장이라면 `Ch07_AI_선형회귀.html` 을 복사해 `script` 경로와 `AIQuiz.start` 의
   두 줄만 고칩니다. 그리고 `AI_ML_atmos.html` 의 `CHAPTERS` 배열에서 그 장의
   `file` 과 `count` 를 채웁니다. `file` 이 비어 있는 장은 준비 중으로 표시됩니다.

`aiquiz.js` 의 채점 규칙이나 `SALT` 를 고치면 **모든 장**의 정답 파일을 다시 만들어야
합니다. 한쪽만 고치면 모든 답이 오답으로 처리됩니다.

## 제출물 확인

`answer/verify_score.html` 에 결과 파일을 붙여 넣으면 서명과 본문을 대조합니다.
서명은 이름, 학번, 제출 시각, 점수, 문항별 시도 횟수와 결과를 모두 합쳐 만든 값이므로
한 글자라도 고치면 어긋납니다.
