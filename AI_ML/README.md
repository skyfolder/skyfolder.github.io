# 대기과학을 위한 인공지능 — 실습

브라우저만 있으면 되는 자율 학습용 실습 페이지이다. 학생은 이름과 학번을 적고
문제를 푼다. 답을 내면 그 자리에서 채점되고 해설이 열리며, 마지막에 문항별
점수와 서명이 담긴 결과 파일을 내려받아 제출한다. 한 문항에 1점이다.

대문은 `AI_ML_atmos.html` 이다. GitHub Pages에 올린 뒤 이 파일 주소를 알려 주면 된다.

## 파일 구성

```
AI_ML_atmos.html                대문 — 장 목록
aiquiz.css                      공용 스타일        ← 모든 장이 함께 쓴다
aiquiz.js                       공용 엔진          ← 정규화 + 채점 + 점수 기록 + 서명

Ch07_AI_선형회귀.html            7장 실습 페이지
Ch07_problems.js                7장 문제 (정답 없음)

answer/
  Ch07_answers.js               7장 정답 해시 + 가려 둔 해설   ← 배포된다
  Ch07_answers.src.js           7장 평문 정답 (강사용)         ← 배포 금지
  build_answers.js              평문 정답 → 해시 정답 변환 도구
  verify_score.html             제출물 검증 (강사용, 배포해도 무방)
.gitignore                      평문 정답을 커밋에서 뺀다
```

## 7장 문항 구성

| 구분 | 문항 | 형식 |
|---|---|---|
| 이론 | 1–15 | 객관식과 한 낱말 단답 |
| 코딩 | 16–30 | 한 줄 코드 입력 |

## 채점 규칙

정답 평문은 배포 파일 어디에도 없다. `answer/ChNN_answers.js` 에는 문항 번호를
섞어 만든 해시와 base64로 가려 둔 해설만 들어 있다. 학생의 입력도 같은 방식으로
해시로 바꾸어 대조한다.

대조하기 전에 입력을 다음과 같이 다듬는다.

- 코딩 문항: 공백을 모두 지우고, 큰따옴표와 굽은 따옴표를 작은따옴표로 바꾸고,
  `#` 뒤의 주석을 떼어 낸다. 대소문자는 구분한다.
- 이론 문항: 공백과 문장부호를 지우고 소문자로 내린다.

덕분에 `X=[[163],[179]]` 와 `X = [[163], [179]]` 는 같은 답으로 처리되고,
`regr` 을 `Regr` 로 쓴 코드는 틀린 답이 된다.

## 정답을 고치거나 새 장을 더할 때

1. `answer/ChNN_answers.src.js` 에 평문 답과 해설을 적는다.
   객관식은 보기 번호를 0부터 세어 적고, 나머지는 받아들일 답을 배열로 적는다.
2. 해시 정답 파일을 다시 만든다.

   ```bash
   node answer/build_answers.js 07
   ```

   문항 수와 검산 결과가 함께 찍힌다. `검산 통과` 가 나와야 한다.
3. 새 장이라면 `Ch07_AI_선형회귀.html` 을 복사해 `script` 경로와 `AIQuiz.start`
   의 두 줄만 고친다. 그리고 `AI_ML_atmos.html` 의 `CHAPTERS` 배열에서 그 장의
   `file` 과 `count` 를 채운다. `file` 이 비어 있는 장은 준비 중으로 표시된다.

`build_answers.js` 의 정규화와 해시는 `aiquiz.js` 와 글자 하나까지 같아야 한다.
한쪽만 고치면 모든 답이 오답으로 처리되므로 주의한다.

## 제출물 확인

`answer/verify_score.html` 에 결과 파일을 붙여 넣으면 서명과 본문을 대조한다.
서명은 이름, 학번, 제출 시각, 점수, 문항별 결과를 모두 합쳐 만든 값이므로
한 글자라도 고치면 어긋난다.
