# score

학생이 제출한 점수 파일이 모이는 곳입니다.

파일 이름은 `이름_챕터_점수.txt` 입니다. 예를 들어 홍길동 학생이 2장에서 43점을 받으면
`홍길동_02_43.txt` 가 됩니다.

파일 안에는 이름·학번·챕터·제출 시각·총점과 함께 문항별 1점 배점이 기록됩니다.
`*` 표시는 학생이 그 문항의 해설을 열어 본 것입니다.

```
========================================================
 FORTRAN 실습 채점 결과
========================================================
 이름   : 홍길동
 학번   : 20241234
 챕터   : 02장 · 프로그램 구조와 기본 문법
 제출   : 2026-09-01 14:22:05
 총점   : 43 / 50   (100점 환산 86.0점)
--------------------------------------------------------
 문항별 점수 · 한 문항 1점
 * 표시는 해설을 열어 본 문항
--------------------------------------------------------
 [복습]  16/18
  01   Colab에 소스 저장하기          1
  02 * 고정형식 1열의 C               0  시도 3회
  ...
--------------------------------------------------------
 복습 16/18   이론 18/20   실습 9/12
 총점 43/50
========================================================
 검증 코드 : 61CF-F008-6294-6FB8
 아래 세 줄은 고치지 마세요. 위조 여부를 확인하는 데 쓰입니다.
--- BEGIN SIGNATURE ---
v1|02|홍길동|20241234|2026-09-01 14:22:05|43|50|110...|001...|61cff00862946fb8
--- END SIGNATURE ---
========================================================
```

## 위조 확인

파일 끝의 검증 코드는 이름·학번·챕터·제출 시각·문항별 정오답을 한 덩어리로 묶어 만든 지문입니다.
`answer/verify_score.html` 을 열고 제출된 `.txt` 를 끌어다 놓으면 한 번에 확인됩니다.
여러 파일을 함께 넣어도 되고, 통과·실패가 표로 정리됩니다.

이름을 바꾸거나 점수를 올리거나 서명 줄을 지우면 모두 `확인 필요` 로 걸립니다.
서명이 통과한 건에 대해서는 검증 페이지가 서명 안의 값으로 이름·학번·정답 수를 다시 보여 주므로,
학생이 보낸 본문이 아니라 검증된 값을 기준으로 성적을 매기면 됩니다.

## 파일이 여기에 들어오는 방법

웹페이지는 서버 폴더에 직접 쓸 수 없습니다. 실제로는 두 경로 중 하나입니다.

1. **학생 PC에서 직접** — 저장소를 내려받아 쓰는 경우, 학생이 제출 화면에서
   `score 폴더에 저장`을 누르고 이 폴더를 지정하면 파일이 바로 여기에 생깁니다.
   (크롬·엣지 데스크톱에서 동작합니다.)
2. **내려받아 제출** — `파일로 내려받기`를 누르면 다운로드 폴더에 같은 이름으로 떨어집니다.
   학생이 LMS나 메일로 제출하면 강사가 이 폴더에 모읍니다.

## 제출물 모으기

`.gitignore` 는 이 폴더의 `.txt` 를 제외하지 않습니다. 학생 점수를 공개 저장소에
올리고 싶지 않다면 `.gitignore` 에 `score/*.txt` 를 추가하세요.
